# Marca

| Arquivo | Onde usar |
|---|---|
| `logo-stacked-dark.png` / `logo-stacked-light.png` | Logo empilhada (mascote em cima): README, capas, páginas. `dark` é para fundo escuro, `light` para fundo claro. |
| `logo-horizontal-dark.png` / `logo-horizontal-light.png` | Logo deitada: cabeçalhos, banners e outros lugares largos. |
| `icon.png` | Ícone do app (1024 px). O `.ico` do Windows fica em `apps/hub/src-tauri/icons/`. |
| `mascot.png` | Só o mascote, fundo transparente. |

Dentro do app vale só a escrita (PARTY em Anton, ANYWHERE em Bungee, verde `#3CF060`), sem o mascote.
As cores dos quatro camaleões são as de P1 a P4: azul `#3B82F6`, vermelho `#EF4444`, verde `#22C55E` e
amarelo `#EAB308`.
